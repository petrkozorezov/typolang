# Специализация программ

Реализовать [специализацию](../../docs/architecture/language/compilation.md)
программы по известным входам и ограничениям, чтобы выполнять доступную работу
заранее и подготавливать программу к компиляции.

Результат — исполняемая остаточная программа с сохранёнными неизвестными
зависимостями и условиями применимости. На выбранных сценариях проверяется
сохранение наблюдаемого поведения.
