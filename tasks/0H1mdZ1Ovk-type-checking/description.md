# Минимальная типизация и проверка типов

Построить небольшой [типизированный слой](../../docs/architecture/language/typing.md)
над реляционным основанием, чтобы проверить возможность описывать и проверять
контракты программ средствами языка.

Результат — проверка и вывод типов для выбранного фрагмента языка,
диагностика нарушений и сохранение открытых обязательств незавершённого кода.
