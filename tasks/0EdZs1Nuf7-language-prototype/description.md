# Прототип вычислительного основания typolang

## Цель

Проработать основание typolang и реализовать прототип, который выполняет
вычисления по согласованным правилам. Это позволит проверить гипотезы
[vision](../../docs/product/vision.md) на конкретной модели и её исполнении.

Задача объединяет исследование, проектирование и реализацию прототипа.
Состав вычислительных возможностей и детали решения уточняются по ходу работы.

## Материалы проработки

Текущая проработка дизайна языка ведётся в [design.md](design.md).

## Результат

- Исполняемый прототип с согласованным набором вычислительных возможностей.
- Описание реализованных правил, существенных ограничений и итогов проверки
  гипотез основания.
- Воспроизводимые проверки поведения прототипа на согласованных примерах.
