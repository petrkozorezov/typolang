# Сквозной прототип typolang

Собрать первый пригодный для программирования прототип на
[реляционном основании](../../docs/architecture/overview.md)
и проверить согласованность его возможностей.

Результат — модульные программы на T-expr, которые можно запускать, исследовать
и исправлять средствами языка. Сквозные сценарии объединяют ленивые рекурсивные
модули, holes, проверки типов и свидетельств, сохраняя исходный код и его связи.

Self-hosting и дальнейшие расширения выполняются отдельными задачами.
