# Состояние исследования

Проверяется базис термов `id`, пара, `def`, `ref` с вычислением через правила
переписывания. [Исполняемая модель](.work/term-basis.py) проверяет выразимость
этого кандидата; она не реализует все контракты текущей архитектуры.

Внешний исполнитель сопоставляет структуру, подставляет захваченные фрагменты,
создаёт свежие идентичности новых объявлений и повторяет корневое переписывание
с приоритетом правил. Готовые ссылки сохраняют цели. Связывание, поиск ссылок,
ленивое вычисление, цитирование и выбор ветвей записаны правилами над термами.

Запуск из корня репозитория, Python 3.9+ без внешних зависимостей:

```sh
python3 tasks/0EdZs1Nuf7-language-prototype/.work/term-basis.py
```

Результат: 22 проверки прошли. Проверены частичное связывание и независимые
применения, свободные входы без предварительного объявления, продуктивная
рекурсия, сохранение захватов при `quote/unquote`, композиция через запасную
ветку и различение несовпадения, неизвестности и ошибки. Правка тела функции
с сохранением локальной или внешней ссылки исполняется правилами самой модели;
исходная версия сохраняется.

Ограничения: WHNF вместо HNF, call-by-name без кеширования результатов.
Не проверены HNF под lambda, разделение вычислений между экземплярами связывания
и возобновление сохранённого остатка после заполнения hole. Нет чтения T-expr,
модулей и общей валидации графа. Бюджет шагов ограничивает эксперимент,
не доказывая завершения или зависания.

Согласование представления и API языка остаётся открытым — см. [R1](review.md).
Эксперимент не меняет объём поставки и не заменяет архитектурные решения.
