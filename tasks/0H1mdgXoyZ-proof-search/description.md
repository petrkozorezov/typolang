# Поиск доказательств

Исследовать автоматизированное построение свидетельств для заданных утверждений,
чтобы упростить работу с контрактами и обоснованными преобразованиями.

Результат — эксперимент на выбранном классе задач, выдающий свидетельства
для независимой проверки. Неудача поиска не означает опровержения утверждения.
