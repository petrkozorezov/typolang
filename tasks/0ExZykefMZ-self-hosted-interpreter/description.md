# Self-hosted исполнитель ядра typolang

## Цель

Написать на typolang исполнитель того же ядра, которое проверено
[первым прототипом](../0EdZs1Nuf7-language-prototype/description.md),
и запустить его на этом прототипе. Эксперимент должен проверить достаточность
языка для реализации собственной семантики и выявить недостающие возможности.

## Результат

- Исполнитель на typolang, воспроизводящий согласованную семантику ядра.
- Воспроизводимый запуск исполнителя через первый прототип.
- Общие сценарии прямого и self-hosted исполнения, сопоставляющие результаты,
  ошибки, открытые зависимости и востребованность, а не только итоговые значения.
- Явная граница внешних операций и описание найденных ограничений основания.

## Ограничения

Исполнитель реализует правила ядра сам; делегирование всей семантики внешнему
`eval` не подтверждает self-hosting. Допустимые внешние операции следует определить
при проектировании, когда станет известен фактический контракт первого прототипа.

Генерация машинного кода, запуск без первого прототипа и компиляция через
специализацию интерпретатора не входят в эту поставку. Self-hosting проверяет
выразительность, но не заменяет пользовательские сценарии первого прототипа.

Референс для исследования —
[Minimal MeTTa](https://trueagi-io.github.io/hyperon-experimental/minimal-metta/).
Конкретный план реализации выбирается после завершения зависимости.
