# Self-hosted исполнитель typolang

Написать исполнитель на typolang и запустить его
[первым прототипом](../0EdZs1Nuf7-language-prototype/description.md),
чтобы проверить достаточность языка для реализации собственной семантики.

Результат — воспроизводимый запуск и общие сценарии для обоих исполнителей,
сопоставляющие результаты, ошибки, открытые обязательства и востребованность.

Исполнитель реализует правила основания сам, с явной границей внешних операций.
Генерация машинного кода и запуск без первого прототипа относятся к другим задачам.
