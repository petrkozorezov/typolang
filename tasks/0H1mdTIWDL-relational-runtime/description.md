# Исполнитель реляционного основания

Реализовать минимальный исполнитель [реляционного основания](../../docs/architecture/language/core.md)
и проверить его согласованность на небольших исполняемых сценариях.

Результат — работающий `run` с открытыми зависимостями, рекурсивными связями,
различимыми исходами и продолжением вычисления. Нужен текстовый debug-лог
по запросу, не вызывающий дополнительного вычисления.
Поддерживаемый фрагмент семантики и его ограничения уточняются при проектировании.
