# Проверка доказательств

Реализовать проверку предъявленных свидетельств утверждений о программах.
Это должно проверить пригодность основания для обоснованных преобразований.

Результат — небольшой проверяющий механизм с явными правилами и границей доверия,
проверенный на примерах, включая обоснование преобразования программы.
Подтверждение, неверное свидетельство и незавершённая проверка различаются.
Поиск доказательств выполняется в отдельной задаче.
