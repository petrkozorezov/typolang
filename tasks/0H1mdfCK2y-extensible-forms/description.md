# Пользовательские грамматические формы

Реализовать [расширение интерпретации форм](../../docs/architecture/language/form-interpretation.md)
средствами языка, чтобы библиотеки могли предоставлять собственную запись отношений.

Результат — явное подключение и композиция грамматических представлений
в модульной программе с сохранением областей имён и установленных связей.
