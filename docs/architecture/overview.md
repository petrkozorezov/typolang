# Архитектура typolang

Вычислительное основание typolang — программируемый реляционный решатель.
Он работает с термами, связываниями и ограничениями; исполнение с конкретными
значениями, проверка свойств и специализация используют это общее основание.

Код представлен данными и получает смысл в контексте интерпретации. Выражения
сохраняют открытые зависимости и доступны программной правке. `run` интерпретирует
термы через отношения контекста, задаёт явную границу вычисления и возвращает
его исход в виде выражения, включая ошибку.
Типизированный язык, модули и средства компиляции строятся над этим основанием.

Здесь зафиксировано выбранное направление, а не завершённая спецификация API.
Непроработанные правила отмечены в соответствующих аспектах. Исходные обязательства
находятся в [целях](../product/goals.md), [принципах](../product/principles.md)
и [требованиях](../product/requirements/language-core.md).

## Устаревшие решения

Прежняя [машина открытых выражений](obsolete/open-expression-machine/README.md)
с позиционными lambda, `bind/reduct`, HNF и приоритетным `match` сохранена для
сравнения. Её API и подробная грамматика не задают новую архитектуру.
Более ранние альтернативы — [единый аргумент-карта](obsolete/map-argument-model.md)
и [макросы с отдельным цитированием графа](obsolete/macros-and-bound-code.md).
