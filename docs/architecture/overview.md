# Архитектура вычислительного основания

Typolang проектируется как язык неизменяемых открытых выражений с ленивым
вычислением и программной работой с кодом. Ниже описан выбранный дизайн,
не реализованная машина: каноническое представление графа и часть контрактов
ещё требуют проработки. Исходные обязательства — в
[требованиях](../product/requirements/language-core.md).

Аспекты ниже пишутся максимально не связанными друг с другом.
Связи добавляются только в случае явной необходимости.

| Аспект | Решения и границы |
| --- | --- |
| [Синтаксис T-expr](language/syntax.md) | Литералы, Unicode, атомы, скобки и отступы |
| [Выражения и идентичности](language/expressions.md) | Объявления, экземпляры, окружение и holes |
| [Ядро и библиотека](language/core.md) | Рабочий состав `core`, библиотека и начальный исполнитель |
| [Применение функций](language/application.md) | Позиции, частичное связывание, `bind` и локальные алиасы |
| [Данные и рекурсия](language/data.md) | Списки, карты, преобразования и `rec` |
| [Модули](language/modules.md) | Карты функций, явное окружение и загрузка зависимостей |
| [Сопоставление](language/matching.md) | Приоритет ветвей, симметричные проверки образца и ошибки вычисления |
| [Ленивое вычисление](language/evaluation.md) | Явный `reduct`, HNF, нормализация, остатки и кеш |
| [Код и цитирование](language/code.md) | Наблюдение функций, границы редукции и сохранение связей |
| [Интерпретация форм](language/form-interpretation.md) | Ленивый `parse` и концепция расширяемых правил вместо макросов |
| [Правки и проверки](language/editing.md) | Пути, границы правки, валидация и оптимизационные замены |

В `obsolete` сохранены прежние варианты для сравнения:
[единственный аргумент-карта](obsolete/map-argument-model.md)
и [макросы с отдельным цитированием графа](obsolete/macros-and-bound-code.md).
Они не задают актуальные контракты.

Решения объясняют потребность, причину выбора, цену и основания пересмотра
рядом с соответствующим механизмом. Непринятые предложения отмечены в самом
аспекте; история обсуждения не заменяет актуальный контракт.
