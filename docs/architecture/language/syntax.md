# Запись T-expr

T-expr — формат записи программы и структурных данных для передачи.
Выбрано Lisp-подобное основание с вложенностью через отступы, позволяющее
обходиться без скобок в обычном коде. Имена записываются с большой буквы
либо выделяются явным префиксом; символы — с маленькой.

Точная грамматика строится по требованиям вычислительного основания.
Примеры скобок, операторов и цитирования в архитектуре поясняют смысл идей,
но пока не задают полный контракт чтения.
Смысл прочитанной формы определяет [интерпретация](form-interpretation.md).

## Открытые вопросы

- Точная лексика имён и символов, литералы, экранирование и комментарии.
- Правила вложенности, явной группировки и записи логических операций,
  кванторов и цитирования.
- Соответствие текстовой записи, структурного представления и печати.

Прежняя подробная грамматика сохранена как
[устаревший вариант](../obsolete/open-expression-machine/syntax.md).
