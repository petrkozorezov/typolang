# Модули

Модуль — карта именованных функций. Определение модуля — функция,
принимающая одну карту окружения и возвращающая карту функций модуля.
Ключи возвращённой карты образуют его публичный интерфейс.

Окружение содержит все доступные модулю внешние средства: `core`, `io`,
`stdlib`, средство загрузки модулей и прочие зависимости. Они передаются явно
через эту карту. Область видимости вызывающего кода не наследуется.

При запуске загружается только корневой модуль проекта. Исполняющая среда
применяет его определение к начальному окружению. Корневой модуль по мере
необходимости загружает другие; они могут загружать свои зависимости.

Загрузка по пути читает файл и возвращает определение модуля. Относительный
путь отсчитывается от файла, в котором он записан. Вызывающий код
применяет полученную функцию к явно выбранному окружению и получает карту
функций модуля.

В пределах одного запуска повторная загрузка того же файла использует
сохранённое определение. Применение к окружению — отдельная операция;
одно определение можно применять к разным окружениям.

Поля карты ленивы: обращение к одной функции не требует вычисления остальных
полей или загрузки невостребованных зависимостей. Рекурсивные связи допустимы;
если вычисление значения требует вычисления этого же значения, возникает
ошибка циклической зависимости.

Загружать зависимости можно в любом месте программы. Рекомендуется объявлять
их на верхнем уровне модуля и передавать нужные функции ниже явно.
Так зависимости видны в одном месте, а внутренние функции получают только
необходимые средства. Ленивость сохраняется независимо от места объявления.
