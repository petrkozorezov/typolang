# Типы и контракты

Выбраны два уровня: нетипизированное вычислительное основание и типизированный
язык над ним. На нижнем уровне описания типов — обычные термы и отношения.
Верхний уровень придаёт им роль типов, вводит проверяемые контракты и удобную
запись типизации. Это сохраняет малый базис и позволяет усиливать гарантии
без обязательной предварительной компиляции.

## Представление и проверка

Рабочая идея конструктора: `(types.int _)` описывает класс целых,
`(types.int 42)` — конкретное значение. Тег с содержимым можно представить
парой. Это схема представления; смысл `_` и точная форма конструктора ещё
не определены.

Проверка контракта функции должна выражаться через всеобщую квантификацию
по допустимым входам. Проверка конкретного вызова даёт более узкую гарантию.
Существование результата, единственность и завершение поиска требуют собственных
условий; они не следуют из одного указания типа результата.

Проверка контракта проверяет заданную программу. Поиск реализации по контракту —
другой запрос: найденное подходящее заполнение не подтверждает исходную программу
для всех допустимых входов.

Спецификация функции может служить источником тестов и документации.
Производные тесты проверяют примеры, а не заменяют универсальное доказательство.
Неподтверждённый контракт сохраняет обязательство; при исполнении проверяются
востребованные свойства, для которых существует динамическая проверка.

Интерпретация типизированной записи добавляет представления типов и требования
к выражениям. Задача специализации — заранее разрешить доступные проверки
и устранить обёртки, которые больше не нужны. Удаление всех типовых данных
для произвольной программы не гарантируется: сами типы могут быть наблюдаемы.

## Вселенные

Направление для исследования — уровни типов через обёртку `(type _)`,
каждая следующая обёртка поднимает уровень. Возможная явная запись — `(type U _)`.
Это гипотеза организации вселенных, а не готовые правила их образования.

## Открытые вопросы

- Связь типа как терма, отношения принадлежности и верхнеуровневого `:`.
- Правила вселенных, рекурсивных типов и квантификации по типам.
- Форма спецификаций и свидетельств, обязательность проверок при исполнении
  и критерий успешной статической проверки.
- Условия безопасного устранения проверок и типовых представлений.
