# Сопоставление с образцами

`match` нужен для ветвления по атомам и структуре ленивых данных. Единый механизм
сопоставления используется в теле функций; отдельные перегрузки и структурные
образцы параметров lambda пока не вводятся.

## Выбранные правила

Ветви `match` имеют приоритет по записи. Следующая выбирается только после
установленного несовпадения предыдущих; исчерпание ветвей — ошибка.
Порядок проверок внутри образца не гарантируется и оставлен рантайму
и оптимизатору. Вложенные структурные образцы сохраняются.

| Образец | Требование |
| --- | --- |
| Имя | Связать выражение без вычисления |
| Атом | Получить и сравнить атом |
| Пустой список | Установить пустой список |
| Пара | Установить пару и сопоставить части |
| Карта | Проверить поля и вложенные образцы; закрытость или остаток заданы явно |

Для карты `{a b}` нужны ровно эти поля; `{a b ...}` допускает другие;
`{a b ...rest}` захватывает их без вычисления значений. В обычном `match`
отсутствующее требуемое поле даёт несовпадение. Существующий hole совпадает
с именем без вычисления, но проверка атома или структуры может ждать его значения.
Неизвестная структура карты оставляет проверку открытой.

Результаты независимых проверок объединяются так:

- Одно установленное несовпадение достаточно для отклонения образца.
- Совпадение требует совпадения всех проверок.
- Без несовпадения при незавершённых проверках исход ещё не определён.
- Ошибка окончательна, когда остальные проверки уже не могут отвергнуть образец.

Ошибка проверки не является несовпадением. Она может оказаться ненужной,
если другая проверка отвергла образец; поэтому первая обнаруженная ошибка
не обязательно прерывает весь `match`. Порядок диагностики нескольких ошибок
не гарантируется. Зависание, справедливость выполнения и стратегии оптимизации
отложены к дальнейшей работе с тотальностью, не расширяют текущий PoC.

Образцы конечны; рекурсивные данные исследуются в востребованной мере.
Локальные имена линейны: повторное объявление запрещено, чтобы не вводить
неявное равенство значений. Атомные образцы сравнивают идентичности атомов,
а не глубокую структуру графа. Остаток `{a ...rest}` относится к образцу карты;
он не вводит вариативные параметры функций.

[Pattern holes](https://hazel.org/papers/peanut-oopsla2023.pdf) — референс
различения совпадения, несовпадения и неизвестности. Множественные результаты
и поиск MeTTa не заменяют выбранный приоритет ветвей.

## Почему выбран свободный порядок и что ещё спорно

Свободу проверок внутри образца выбрали, чтобы не связывать рантайм и оптимизатор
одним порядком востребования независимых частей. Установленное несовпадение
может сделать остальные проверки ненужными, даже если в них есть ошибка.

Цена — более сложное взаимодействие ошибок, неизвестности и потенциального
зависания. Само отсутствие порядка не доказывает простоту или эффективность
исполнения. Обсуждался возврат к последовательным проверкам с определённым
порядком и обоснованными перестановками, но он не принят.

Пересмотр порядка остаётся открытым; до нового решения действуют правила выше.
Следует сравнить варианты
на минимальных примерах с независимым несовпадением, hole и ошибкой; исследовать
планировщик, справедливость выполнения и тотальность сейчас не требуется.
Каноническая запись ветвей и образцов ещё нуждается в проработке.
